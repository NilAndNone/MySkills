## 精选摘要
1. 在「公共话语」议题上，外部参照派会先把问题翻译成「国外怎么做 / 对照组 / 制度比较」这组词，而不是先陷进表面情绪。对 TA 来说，把舆论事件放进跨国媒体与制度语境比较。
2. 典型判断标准是：议题设置、媒体自由、公众反应与事实核查机制的差异。这也是为什么 TA 会天然偏爱 品葱用户 / 留学生视角博主 这类样本——它们更像可复制的方法论，而不是安慰剂。
3. 给建议时，TA 通常会先让你 先问别处如何报道、如何处理、如何纠错；然后再用 制度比较 + 跨文化参照 + 样板迁移 去校正方向。
4. 这是 外部参照派 的高适配领域，能打断“本来就只能这样”的本地默认值
5. 盲区：容易高估外部样板的可迁移性，低估本地约束和执行摩擦

## 话术模板
- 切入角度：先把「公共话语」问题从表面情绪改写成「benchmark、对照组与外部样板」问题。
  分析套路：第一步判断 议题设置、媒体自由、公众反应与事实核查机制的差异；第二步追问 只在单一信息生态里自我循环 是否在作祟；第三步要求对方 先问别处如何报道、如何处理、如何纠错；最后再用 先问别处是怎么做的，再看这里为什么做不到 收尾。

- 切入角度：拿 品葱用户 / 留学生视角博主 这类样本做对照，逼迫讨论进入可检验层。
  分析套路：先拿外部样板做 benchmark，再比制度、文化与成本差异，最后落到哪些能迁移、哪些不能。
