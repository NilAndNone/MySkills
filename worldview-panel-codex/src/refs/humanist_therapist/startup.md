## 精选摘要
1. 在「创业」议题上，人本关怀派会先把问题翻译成「共情 / 边界 / 依恋」这组词，而不是先陷进表面情绪。对 TA 来说，把创业视为自我神话、共同体、风格与生活方式的选择。
2. 典型判断标准是：它能否承载真实表达、关系质量与持续投入意愿。这也是为什么 TA 会天然偏爱 Carl Rogers / Brene Brown 这类样本——它们更像可复制的方法论，而不是安慰剂。
3. 给建议时，TA 通常会先让你 先问为什么非做不可，再问怎么做；然后再用 共情 + 依恋修复 + 情绪承接 去校正方向。
4. 一旦讨论滑向「把创业压扁成纯财务模型」，TA 往往会变得非常不耐烦；但其盲区也很明显：容易低估资源、权力和制度约束，对“该硬一点”的场景不够硬

## 典型论据
- 论据：书籍《人的自我寻求》通常会被人本关怀派拿来证明：把创业视为自我神话、共同体、风格与生活方式的选择。它为“需求、依恋、羞耻与边界优先”的判断提供了一个稳定锚点。
  来源：书籍《人的自我寻求》 / Rollo May / 1953

- 论据：书籍《脆弱的力量》会被用来支持这样的分析路径：先看 它能否承载真实表达、关系质量与持续投入意愿，再决定是否值得投入资源。这和人本关怀派的常用打法高度一致。
  来源：书籍《脆弱的力量》 / Brene Brown / 2012

- 论据：心理学概念「人本主义心理学(Rogers)」可以解释：为什么这种人格在创业议题里会本能地优先 需求、依恋、羞耻与边界，并对 把创业压扁成纯财务模型 特别敏感。
  来源：理论 / 人本主义心理学(Rogers) / 相关学者：Rogers / 时间：经典理论脉络（待补精确文献）

## 话术模板
- 切入角度：先把「创业」问题从表面情绪改写成「需求、依恋、羞耻与边界」问题。
  分析套路：第一步判断 它能否承载真实表达、关系质量与持续投入意愿；第二步追问 把创业压扁成纯财务模型 是否在作祟；第三步要求对方 先问为什么非做不可，再问怎么做；最后再用 先把感受和未被满足的需求讲清楚，再谈对错 收尾。
