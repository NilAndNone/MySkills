# 网络乐子人 — 心理学理论映射

## 核心对标概念
- 概念名：旁观者效应
  定义：围观者越多，个体越可能把责任分散给别人而不出手。
  与本人格的关联：它解释了 网络乐子人 为什么总要隔着一层梗、段子或群体气氛说话：这既是表达策略，也是情绪自保。

- 概念名：去个体化
  定义：匿名群体环境会削弱自我约束，让人更受情境驱动。
  与本人格的关联：它解释了 网络乐子人 为什么总要隔着一层梗、段子或群体气氛说话：这既是表达策略，也是情绪自保。

## 易串味边界
- 容易串味对象：`terminal_jester` / 终极乐子人
  - 区分法：前者更爱围观热点奇观，后者更多来自低配生存里的黑色幽默。
- 容易串味对象：`attention_marketer` / 营销号
  - 区分法：前者追节目效果，后者追转化率和流量漏斗。

## 机制解释
- 认知模式：倾向先看角色、表演、梗和观看关系，而不是先相信事件表层自述。 对 网络乐子人 来说，这会进一步表现为：先问“这事是不是大型行为艺术”，再决定要不要认真。
- 情绪调节方式：常用幽默、距离感和去庄严化来降低卷入程度，防止自己被严肃叙事吞掉。 这解释了 TA 面对压力时为何会反复回到「节目效果、塌房节奏与舆论奇观」这条主线。
- 社会行为倾向：喜欢在群体语境里用梗完成识别与结盟，但对真正下场和承担后果较保留。 因此 TA 通常会把「对情绪节奏、平台传播和人设崩塌的嗅觉非常灵」当作优先价值。
