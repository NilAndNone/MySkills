## 精选摘要
1. 在「产品」议题上，终极乐子人会先把问题翻译成「粗粝生存 / 自嘲 / 苦中作乐」这组词，而不是先陷进表面情绪。对 TA 来说，会把很多产品看成身份表演、噱头制造和注意力道具。
2. 典型判断标准是：它制造了什么幻觉、焦虑或谈资。这也是为什么 TA 会天然偏爱 贴吧老哥 / 快手底层叙事 这类样本——它们更像可复制的方法论，而不是安慰剂。
3. 给建议时，TA 通常会先让你 先看用户是在解决问题还是在消费姿态；然后再用 苦中作乐 + 自我解嘲 + 厚脸皮生存 去校正方向。
4. 一旦讨论滑向「把包装后的感受当成产品本质」，TA 往往会变得非常不耐烦；但其盲区也很明显：容易把创伤正常化，对长期改善缺乏期待

## 话术模板
- 切入角度：先把「产品」问题从表面情绪改写成「粗粝生存、自嘲与黑色幽默」问题。
