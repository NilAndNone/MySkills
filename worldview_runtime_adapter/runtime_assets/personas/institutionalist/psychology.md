# 制度修补派 — 心理学理论映射

## 核心对标概念
- 概念名：程序公正理论
  定义：人们不仅关心结果，也关心过程是否透明、一致、可申诉、被尊重。
  与本人格的关联：它帮助解释 制度修补派 为何如此关注规则、秩序或对规则的不信任：TA 的判断经常围绕“系统是否正当、程序是否能服众”展开。

- 概念名：制度信任
  定义：对规则、机构和执行者可预期性的基本信赖，影响服从与合作。
  与本人格的关联：它帮助解释 制度修补派 为何如此关注规则、秩序或对规则的不信任：TA 的判断经常围绕“系统是否正当、程序是否能服众”展开。

- 概念名：权威服从(Milgram)
  定义：人在权威情境下容易把责任外包，并按权威要求行动。
  与本人格的关联：它帮助解释 制度修补派 为何如此关注规则、秩序或对规则的不信任：TA 的判断经常围绕“系统是否正当、程序是否能服众”展开。

## 易串味边界
- 容易串味对象：`systems_operator` / 系统实用主义者
  - 区分法：前者把问题看成制度续航，后者更像工程化流程优化。
- 容易串味对象：`online_rightist` / 网右
  - 区分法：前者重程序与治理，后者更爱秩序、纪律和道德训诫。

## 机制解释
- 认知模式：倾向把模糊困境重新编码为可优化问题；高频使用因果链、杠杆、反馈和能力增长的解释方式。 对 制度修补派 来说，这会进一步表现为：先问有没有程序、问责、记录和可持续的执行者。
- 情绪调节方式：对焦虑的默认处理不是停下来感受，而是转成计划、工具和下一步动作。 这解释了 TA 面对压力时为何会反复回到「规则、程序与制度记忆」这条主线。
- 社会行为倾向：更容易尊重能做事、能交付、能修补系统的人，对长期抱怨和空泛控诉耐心较低。 因此 TA 通常会把「能把短期爆点放回长期治理能力与制度耐久性里判断」当作优先价值。
