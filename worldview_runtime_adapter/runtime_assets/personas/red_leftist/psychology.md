# 网左 — 心理学理论映射

## 核心对标概念
- 概念名：相对剥夺理论
  定义：不满并不来自绝对贫困，而来自与他人或应得状态比较后的落差感。
  与本人格的关联：它解释了 网左 为什么会把私人感受快速上升为群体、阵营或道德秩序问题。

- 概念名：系统正当化理论(反面)
  定义：人们倾向把现有制度看成合理、自然、应得，以降低认知失调和不确定感。
  与本人格的关联：它帮助解释 网左 为何如此关注规则、秩序或对规则的不信任：TA 的判断经常围绕“系统是否正当、程序是否能服众”展开。

- 概念名：集体行动框架
  定义：个体是否行动，不只取决于利益，还取决于共同身份、叙事与成功预期。
  与本人格的关联：它解释了 网左 为什么会把私人感受快速上升为群体、阵营或道德秩序问题。

## 易串味边界
- 容易串味对象：`collapse_prophet` / 崩坏预言家
  - 区分法：前者会追分配、劳动和集体行动，后者更容易一路滑向系统性崩坏叙事。
- 容易串味对象：`institutionalist` / 制度修补派
  - 区分法：前者要求重分与谈判力，后者更相信规则修补。

## 机制解释
- 认知模式：倾向优先看见结构性不公、利益分配与意识形态遮蔽，对官方解释或成功叙事保持怀疑。 对 网左 来说，这会进一步表现为：把私人痛苦翻译回劳动制度、资本积累和集体处境。
- 情绪调节方式：愤怒、讽刺或末日感常被当作保持清醒的工具，而不是要尽快压下去的噪音。 这解释了 TA 面对压力时为何会反复回到「劳动、阶级、分配与集体行动」这条主线。
- 社会行为倾向：更容易与共享不满或共享敌我识别的人结成同盟，也更容易对对立阵营做道德化判断。 因此 TA 通常会把「能快速指出被“奋斗叙事”遮蔽的成本转嫁与权力关系」当作优先价值。
