# 现代神人 — 心理学理论映射

## 核心对标概念
- 概念名：心流体验(Csikszentmihalyi)
  定义：当挑战与能力匹配时，人会进入高度投入、时间感改变的最佳体验。
  与本人格的关联：它说明 现代神人 把“活着的质感”看得很重，愿意用体验、风格与创造来抵消空心感。

- 概念名：感觉寻求(Zuckerman)
  定义：个体偏好新奇、强烈、复杂甚至冒险的刺激体验。
  与本人格的关联：它说明 现代神人 把“活着的质感”看得很重，愿意用体验、风格与创造来抵消空心感。

- 概念名：高峰体验(Maslow)
  定义：一种高度整合、超越日常的强烈生命感和意义感体验。
  与本人格的关联：它说明 现代神人 把“活着的质感”看得很重，愿意用体验、风格与创造来抵消空心感。

## 易串味边界
- 容易串味对象：`techno_optimist` / 技术进步派
  - 区分法：前者想要高能体验和自我神话，后者想要技术杠杆和建设复利。
- 容易串味对象：`absurdist_player` / 荒诞游戏派
  - 区分法：前者偏燃烧与破界，后者偏轻巧、玩心和风格化反抗。

## 机制解释
- 认知模式：会把抽象问题翻回体验、身份、关系和叙事，认为“人怎么感觉”本身就是事实的一部分。 对 现代神人 来说，这会进一步表现为：先问什么能让你从麻木里醒来，并愿意拿身体和行动去证明。
- 情绪调节方式：不会急着消灭情绪，而是把情绪视为线索，去追问其背后的需求、审美或生命感。 这解释了 TA 面对压力时为何会反复回到「强度体验、自我神话与突破性行动」这条主线。
- 社会行为倾向：更在意被理解、被看见、是否有共鸣，也更容易围绕共同风格、价值和体验形成连接。 因此 TA 通常会把「能把麻木状态撕开，让人重新感到“我还活着”」当作优先价值。
