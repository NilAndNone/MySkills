# 01_执行当前里程碑

把下面整段发给 Codex：

```text
执行 `docs/exec/current.md` 的当前 milestone，严格按固定编排，不要自由发挥。

阶段 A：准备
1. 读取：
   - `AGENTS.md`
   - `docs/exec/current.md`
   - `docs/testing_contract.md`
   - `docs/code_review.md`
2. 先只总结：
   - 当前 milestone
   - touched files
   - validation commands
   - acceptance
3. 这一步不要改代码。

阶段 B：实现
1. Spawn 1 个 `codegen` 子 agent。
2. 对 `codegen` 显式使用：
   - $implementation-strategy
   - $code-change-verification
3. 只实现当前 milestone。
4. 只有 `codegen` 可以修改产品代码。
5. `codegen` 完成后，返回：
   - changed files
   - commands run
   - PASS/FAIL
   - 新增/修改的 unit tests

阶段 C：测试与审查
1. 在 `codegen` 完成后，再并行 spawn：
   - 1 个 `integration_tester` 子 agent，显式使用 $client-integration-from-unit-tests
   - 1 个 `cr` 子 agent，显式使用 $anti-fallback-review
2. `integration_tester` 只允许修改 `client/` 下测试相关文件。
3. `integration_tester` 必须读取 `codegen` 本次新增/修改的 unit tests，再派生 client 集成测试。
4. `cr` 必须保持只读。
5. 等两个子 agent 都结束后再继续。

阶段 D：汇总
只返回：
1. 当前 milestone 是否通过
2. changed files
3. unit test -> client integration test 映射
4. validation 结果
5. blocking issues
6. 建议：continue / fix / stop

硬限制：
- 不允许扩 scope
- 不允许提前开启下一个 milestone
- 不允许新增 broad fallback code
- 不允许把 dead code 留在当前 diff 里
```
