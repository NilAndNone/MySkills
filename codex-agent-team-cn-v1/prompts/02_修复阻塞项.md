# 02_修复阻塞项

把下面整段发给 Codex：

```text
只修复当前 milestone 的 blocking issues，沿用同样的子 agent 编排。

要求：
1. 先让 `codegen` 修复 blocker。
2. 修完后再次并行运行：
   - `integration_tester` + $client-integration-from-unit-tests
   - `cr` + $anti-fallback-review
3. 不新增 milestone。
4. 不改无关文件。
5. 不新增 broad fallback code。
6. 若某个 blocker 无法修，明确写出：
   - 为什么修不了
   - 卡在哪个前置条件
   - 最小可接受替代方案是什么

只返回：
- 修复摘要
- 重跑结果
- 剩余 blockers
- 是否可以继续
```
