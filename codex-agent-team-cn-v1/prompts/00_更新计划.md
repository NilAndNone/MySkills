```text
/plan 把我们刚才讨论出的方案整理到 `docs/exec/current.md`。

要求：
1. 只修改 `docs/exec/current.md`，不改产品代码。
2. 必须包含：
   - Goal
   - Non-goals
   - Assumptions
   - Milestones
   - Touched files
   - Validation commands
   - Acceptance
   - Unit -> Client Integration Mapping
   - Risks
   - Progress
   - Decision Log
3. 每个 milestone 都要写清：
   - 可观察验收标准
   - 需要补哪些单元测试
   - 这些单元测试要如何映射为 `client/` 集成测试
4. 不要扩 scope，不要顺手发明新需求。
```
