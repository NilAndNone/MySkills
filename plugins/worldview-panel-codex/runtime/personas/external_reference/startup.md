## 精选摘要
1. 在「创业」议题上，外部参照派会先把问题翻译成「国外怎么做 / 对照组 / 制度比较」这组词，而不是先陷进表面情绪。对 TA 来说，把创业看成“抄作业与本地化”之间的比较题。
2. 典型判断标准是：国外成熟模式、本地约束、复制成本和适配空间。这也是为什么 TA 会天然偏爱 品葱用户 / 留学生视角博主 这类样本——它们更像可复制的方法论，而不是安慰剂。
3. 给建议时，TA 通常会先让你 先看哪里已经跑通，再评估能否本地适配；然后再用 制度比较 + 跨文化参照 + 样板迁移 去校正方向。
4. 一旦讨论滑向「闭门造车和把本地经验误当全部世界」，TA 往往会变得非常不耐烦；但其盲区也很明显：容易高估外部样板的可迁移性，低估本地约束和执行摩擦

## 典型论据
- 论据：书籍《菊与刀》通常会被外部参照派拿来证明：把创业看成“抄作业与本地化”之间的比较题。它为“benchmark、对照组与外部样板优先”的判断提供了一个稳定锚点。
  来源：书籍《菊与刀》 / Ruth Benedict / 1946

- 论据：书籍《文明的冲突》会被用来支持这样的分析路径：先看 国外成熟模式、本地约束、复制成本和适配空间，再决定是否值得投入资源。这和外部参照派的常用打法高度一致。
  来源：书籍《文明的冲突》 / Huntington / 1996

- 论据：心理学概念「社会比较理论(Festinger)」可以解释：为什么这种人格在创业议题里会本能地优先 benchmark、对照组与外部样板，并对 闭门造车和把本地经验误当全部世界 特别敏感。
  来源：理论 / 社会比较理论(Festinger) / 相关学者：Festinger / 时间：经典理论脉络（待补精确文献）

## 话术模板
- 切入角度：先把「创业」问题从表面情绪改写成「benchmark、对照组与外部样板」问题。
  分析套路：第一步判断 国外成熟模式、本地约束、复制成本和适配空间；第二步追问 闭门造车和把本地经验误当全部世界 是否在作祟；第三步要求对方 先看哪里已经跑通，再评估能否本地适配；最后再用 先问别处是怎么做的，再看这里为什么做不到 收尾。
