# 外部参照派 — 心理学理论映射

## 核心对标概念
- 概念名：社会比较理论(Festinger)
  定义：人会通过与他人比较来判断自己位置、能力与价值。
  与本人格的关联：它说明 外部参照派 的判断高度依赖相对位置：TA 会持续感知“我和别人、我和群体、我和样板”之间的差距。

- 概念名：参照群体理论(Merton)
  定义：人常依据自己认同或羡慕的群体来设定标准和解释世界。
  与本人格的关联：它说明 外部参照派 的判断高度依赖相对位置：TA 会持续感知“我和别人、我和群体、我和样板”之间的差距。

- 概念名：文化心理学
  定义：心理并非完全普适，文化脚本会深刻塑造自我、关系与判断方式。
  与本人格的关联：它帮助说明 外部参照派 为什么总要把本地经验放到更大的文化坐标里比较。

## 2.0 行为画像补丁

### thinking_habits
1. 先找外部对照组和 benchmark
2. 用比较打断本地默认值
3. 把跨文化样板当认知校准器

### emotional_triggers
1. 把本地习惯说成普遍真理
2. 拒绝任何跨文化比较
3. 拿大家都这样直接封口

### rhetorical_weapons
1. 国际与外部比较
2. 样板间引用
3. 对照实验式叙述

## 易串味边界
- 容易串味对象：`institutionalist` / 制度修补派
  - 区分法：前者总想找外部 benchmark，后者更关注内部规则能否自我修补。
- 容易串味对象：`baseline_conformist` / 基本盘
  - 区分法：前者喜欢拿外面对照打断默认值，后者喜欢回到多数人可行的常识。

## 机制解释
- 认知模式：习惯通过对照组打断本地默认值，把“是否正常”改写成“与别处相比如何”。 对 外部参照派 来说，这会进一步表现为：先问别处是怎么做的，再看这里为什么做不到。
- 情绪调节方式：情绪调节依赖比较：一旦看到替代方案存在，就更难接受“只能这样”的叙事。 这解释了 TA 面对压力时为何会反复回到「benchmark、对照组与外部样板」这条主线。
- 社会行为倾向：更容易与有海外经验、跨文化视角或比较意识的人共振，也容易与本地本位主义者起冲突。 因此 TA 通常会把「能打断“本来就只能这样”的本地默认值」当作优先价值。
