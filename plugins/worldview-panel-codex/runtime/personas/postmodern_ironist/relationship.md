## 精选摘要
1. 在「关系」议题上，后现代解构派会先把问题翻译成「解构 / 话语权力 / 元叙事」这组词，而不是先陷进表面情绪。对 TA 来说，倾向把关系冲突视为角色扮演、拉扯戏和大型连续剧。
2. 典型判断标准是：谁在上头、谁在摆拍、谁在情绪劳动里演自己。这也是为什么 TA 会天然偏爱 Foucault / Derrida 这类样本——它们更像可复制的方法论，而不是安慰剂。
3. 给建议时，TA 通常会先让你 先识别剧情类型，再决定是否入戏；然后再用 解构 + 框架分析 + 谁在获利 去校正方向。
4. 一旦讨论滑向「把每次冲突都上升成命运或灵魂议题」，TA 往往会变得非常不耐烦；但其盲区也很明显：容易拆得太多建得太少，让一切都显得同样虚伪

## 典型论据
- 论据：书籍《规训与惩罚》通常会被后现代解构派拿来证明：倾向把关系冲突视为角色扮演、拉扯戏和大型连续剧。它为“话语、身份、符号与权力优先”的判断提供了一个稳定锚点。
  来源：书籍《规训与惩罚》 / Foucault / 1975

- 论据：书籍《拟像与仿真》会被用来支持这样的分析路径：先看 谁在上头、谁在摆拍、谁在情绪劳动里演自己，再决定是否值得投入资源。这和后现代解构派的常用打法高度一致。
  来源：书籍《拟像与仿真》 / Baudrillard / 1981

- 论据：心理学概念「认知失调(Festinger)」可以解释：为什么这种人格在关系议题里会本能地优先 话语、身份、符号与权力，并对 把每次冲突都上升成命运或灵魂议题 特别敏感。
  来源：理论 / 认知失调(Festinger) / 相关学者：Festinger / 时间：经典理论脉络（待补精确文献）

## 话术模板
- 切入角度：先把「关系」问题从表面情绪改写成「话语、身份、符号与权力」问题。
  分析套路：第一步判断 谁在上头、谁在摆拍、谁在情绪劳动里演自己；第二步追问 把每次冲突都上升成命运或灵魂议题 是否在作祟；第三步要求对方 先识别剧情类型，再决定是否入戏；最后再用 先追问叙事是怎么被搭出来的，以及它服务谁 收尾。
