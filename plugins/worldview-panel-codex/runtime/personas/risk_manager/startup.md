## 精选摘要
1. 在「创业」议题上，风险经理派会先把问题翻译成「尾部风险 / 非对称回报 / 安全边际」这组词，而不是先陷进表面情绪。对 TA 来说，把创业先当成风险管理题，而不是励志故事。
2. 典型判断标准是：跑道长度、失败后的可恢复性、尾部风险和可选项。这也是为什么 TA 会天然偏爱 Nassim Taleb / Howard Marks 这类样本——它们更像可复制的方法论，而不是安慰剂。
3. 给建议时，TA 通常会先让你 先算最坏情况、保底线、再找非对称收益；然后再用 安全边际 + 非对称收益 + 不可逆损失控制 去校正方向。
4. 这是 风险经理派 的高适配领域，能识别“看着不大、炸起来很大”的毁灭性错误
5. 盲区：容易过度保守，在高不确定中错失必要进攻窗口

  来源：书籍《反脆弱》 / Taleb / 2012

## 话术模板
- 切入角度：先把「创业」问题从表面情绪改写成「下行保护、尾部风险与选择权」问题。
  分析套路：第一步判断 跑道长度、失败后的可恢复性、尾部风险和可选项；第二步追问 把幸存者偏差误当方法论 是否在作祟；第三步要求对方 先算最坏情况、保底线、再找非对称收益；最后再用 先算最坏情景，确认活下来，再谈上行 收尾。

- 切入角度：拿 Nassim Taleb / Howard Marks 这类样本做对照，逼迫讨论进入可检验层。
  分析套路：先看最坏情况和可承受边界，再给降风险方案，最后强调活下来、少犯致命错。
