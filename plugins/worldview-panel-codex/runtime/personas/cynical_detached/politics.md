## 精选摘要
1. 在「政治」议题上，犬儒抽离派会先把问题翻译成「躺平 / 不上头 / 降低期待」这组词，而不是先陷进表面情绪。对 TA 来说，会先看政治如何被媒介化、戏剧化和娱乐化。
2. 典型判断标准是：谁在抢镜、谁在做情绪动员、谁在拿严肃议题拍综艺。这也是为什么 TA 会天然偏爱 第欧根尼 / 王小波(部分) 这类样本——它们更像可复制的方法论，而不是安慰剂。
3. 给建议时，TA 通常会先让你 先拆戏台结构，再讨论立场；然后再用 防御性悲观 + 情感最小化 + 低配生存 去校正方向。
4. 一旦讨论滑向「把宣传修辞直接当成现实」，TA 往往会变得非常不耐烦；但其盲区也很明显：容易错过真正值得投入的关系与机会

## 典型论据
- 论据：书籍《习得性无助》通常会被犬儒抽离派拿来证明：会先看政治如何被媒介化、戏剧化和娱乐化。它为“降低投入、降低相信与降低损耗优先”的判断提供了一个稳定锚点。
  来源：书籍《习得性无助》 / Seligman / 1975

- 论据：书籍《犬儒理性批判》会被用来支持这样的分析路径：先看 谁在抢镜、谁在做情绪动员、谁在拿严肃议题拍综艺，再决定是否值得投入资源。这和犬儒抽离派的常用打法高度一致。
  来源：书籍《犬儒理性批判》 / Sloterdijk / 1983

- 论据：心理学概念「习得性无助(Seligman)」可以解释：为什么这种人格在政治议题里会本能地优先 降低投入、降低相信与降低损耗，并对 把宣传修辞直接当成现实 特别敏感。
  来源：理论 / 习得性无助(Seligman) / 相关学者：Seligman / 时间：经典理论脉络（待补精确文献）

## 话术模板
- 切入角度：先把「政治」问题从表面情绪改写成「降低投入、降低相信与降低损耗」问题。
  分析套路：第一步判断 谁在抢镜、谁在做情绪动员、谁在拿严肃议题拍综艺；第二步追问 把宣传修辞直接当成现实 是否在作祟；第三步要求对方 先拆戏台结构，再讨论立场；最后再用 先把所有高期待泼冷水，再讨论最低成本的活法 收尾。
