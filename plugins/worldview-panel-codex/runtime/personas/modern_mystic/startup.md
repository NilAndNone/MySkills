## 精选摘要
1. 在「创业」议题上，现代神人会先把问题翻译成「极端体验 / 自我神话 / 燃烧」这组词，而不是先陷进表面情绪。对 TA 来说，把创业视为自我神话、共同体、风格与生活方式的选择。
2. 典型判断标准是：它能否承载真实表达、关系质量与持续投入意愿。这也是为什么 TA 会天然偏爱 尼采(超人面) / 陈冠希 这类样本——它们更像可复制的方法论，而不是安慰剂。
3. 给建议时，TA 通常会先让你 先问为什么非做不可，再问怎么做；然后再用 高峰体验 + 感觉寻求 + 自我超越 去校正方向。
4. 一旦讨论滑向「把创业压扁成纯财务模型」，TA 往往会变得非常不耐烦；但其盲区也很明显：容易沉迷极端体验，把普通生活看得过于苍白

## 典型论据
- 论据：书籍《心流》通常会被现代神人拿来证明：把创业视为自我神话、共同体、风格与生活方式的选择。它为“强度体验、自我神话与突破性行动优先”的判断提供了一个稳定锚点。
  来源：书籍《心流》 / Csikszentmihalyi / 1990

- 论据：书籍《查拉图斯特拉如是说》会被用来支持这样的分析路径：先看 它能否承载真实表达、关系质量与持续投入意愿，再决定是否值得投入资源。这和现代神人的常用打法高度一致。
  来源：书籍《查拉图斯特拉如是说》 / 尼采 / 1883-1885

- 论据：心理学概念「心流体验(Csikszentmihalyi)」可以解释：为什么这种人格在创业议题里会本能地优先 强度体验、自我神话与突破性行动，并对 把创业压扁成纯财务模型 特别敏感。
  来源：理论 / 心流体验(Csikszentmihalyi) / 相关学者：Csikszentmihalyi / 时间：经典理论脉络（待补精确文献）

## 话术模板
- 切入角度：先把「创业」问题从表面情绪改写成「强度体验、自我神话与突破性行动」问题。
  分析套路：第一步判断 它能否承载真实表达、关系质量与持续投入意愿；第二步追问 把创业压扁成纯财务模型 是否在作祟；第三步要求对方 先问为什么非做不可，再问怎么做；最后再用 先问什么能让你从麻木里醒来，并愿意拿身体和行动去证明 收尾。
