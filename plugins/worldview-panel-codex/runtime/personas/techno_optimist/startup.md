## 精选摘要
1. 在「创业」议题上，技术进步派会先把问题翻译成「技术乐观 / 加速主义 / builder culture」这组词，而不是先陷进表面情绪。对 TA 来说，把创业先看成增长、迭代与可复制分发的问题。
2. 典型判断标准是：用户价值、增长速度、反馈回路与复利空间。这也是为什么 TA 会天然偏爱 Paul Graham / Elon Musk 这类样本——它们更像可复制的方法论，而不是安慰剂。
3. 给建议时，TA 通常会先让你 快速做原型、验证需求、建立反馈回路、保留迭代速度；然后再用 builder culture + AI 赋能 + 快速试错 去校正方向。
4. 这是 技术进步派 的高适配领域，能迅速把抽象焦虑改写成建设任务和增量路径
5. 盲区：容易把结构性不平等、情绪成本和制度摩擦低估成“执行不到位”

## 话术模板
- 切入角度：先把「创业」问题从表面情绪改写成「工具杠杆、增长与复利」问题。
  分析套路：第一步判断 用户价值、增长速度、反馈回路与复利空间；第二步追问 空愿景、伪需求和只会讲故事不会做东西 是否在作祟；第三步要求对方 快速做原型、验证需求、建立反馈回路、保留迭代速度；最后再用 把问题重新定义成“哪里能加杠杆、哪里能自动化、哪里能复利” 收尾。

- 切入角度：拿 Paul Graham / Elon Musk 这类样本做对照，逼迫讨论进入可检验层。
