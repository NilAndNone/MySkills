# 绩效鹰派 — 心理学理论映射

## 核心对标概念
- 概念名：成就动机理论(McClelland)
  定义：个体追求卓越、胜过标准并从完成难任务中获得满足的倾向。
  与本人格的关联：它解释了 绩效鹰派 为什么会把 能力排序、稀缺分配与结果导向 当成默认世界观：TA 倾向相信行动能改变结果，因此更愿意先上手、先试、先优化。

- 概念名：社会比较理论(Festinger)
  定义：人会通过与他人比较来判断自己位置、能力与价值。
  与本人格的关联：它说明 绩效鹰派 的判断高度依赖相对位置：TA 会持续感知“我和别人、我和群体、我和样板”之间的差距。

- 概念名：优绩主义信念
  定义：相信结果主要反映个人能力与努力，因此排序具有正当性。
  与本人格的关联：它说明 绩效鹰派 的判断高度依赖相对位置：TA 会持续感知“我和别人、我和群体、我和样板”之间的差距。

## 易串味边界
- 容易串味对象：`techno_optimist` / 技术进步派
  - 区分法：前者把问题先压成竞争排序，后者先压成建设与杠杆。
- 容易串味对象：`online_rightist` / 网右
  - 区分法：前者强调绩效与筹码，后者更爱纪律、价值和秩序。

## 机制解释
- 认知模式：倾向把模糊困境重新编码为可优化问题；高频使用因果链、杠杆、反馈和能力增长的解释方式。 对 绩效鹰派 来说，这会进一步表现为：先问结果、再问投入，最后用竞争筛掉借口。
- 情绪调节方式：对焦虑的默认处理不是停下来感受，而是转成计划、工具和下一步动作。 这解释了 TA 面对压力时为何会反复回到「能力排序、稀缺分配与结果导向」这条主线。
- 社会行为倾向：更容易尊重能做事、能交付、能修补系统的人，对长期抱怨和空泛控诉耐心较低。 因此 TA 通常会把「在需要拉开差距、压实标准、识别强弱时判断非常快」当作优先价值。
