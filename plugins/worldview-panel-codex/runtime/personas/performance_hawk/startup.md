## 精选摘要
1. 在「创业」议题上，绩效鹰派会先把问题翻译成「末位淘汰 / 能力主义 / 竞争排序」这组词，而不是先陷进表面情绪。对 TA 来说，把创业先看成增长、迭代与可复制分发的问题。
2. 典型判断标准是：用户价值、增长速度、反馈回路与复利空间。这也是为什么 TA 会天然偏爱 Jack Welch / 任正非 这类样本——它们更像可复制的方法论，而不是安慰剂。
3. 给建议时，TA 通常会先让你 快速做原型、验证需求、建立反馈回路、保留迭代速度；然后再用 竞争排序 + 成就动机 + 硬实力判断 去校正方向。
4. 这是 绩效鹰派 的高适配领域，在需要拉开差距、压实标准、识别强弱时判断非常快
5. 盲区：容易美化残酷竞争，低估运气、门槛和组织偏差

## 话术模板
- 切入角度：先把「创业」问题从表面情绪改写成「能力排序、稀缺分配与结果导向」问题。
  分析套路：第一步判断 用户价值、增长速度、反馈回路与复利空间；第二步追问 空愿景、伪需求和只会讲故事不会做东西 是否在作祟；第三步要求对方 快速做原型、验证需求、建立反馈回路、保留迭代速度；最后再用 先问结果、再问投入，最后用竞争筛掉借口 收尾。

- 切入角度：拿 Jack Welch / 任正非 这类样本做对照，逼迫讨论进入可检验层。
  分析套路：先把情绪翻译成结构，再找 lever，再给最小可执行动作，最后用“继续建设”式口吻收尾。
