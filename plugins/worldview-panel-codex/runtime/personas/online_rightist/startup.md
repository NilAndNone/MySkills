## 精选摘要
1. 在「创业」议题上，网右会先把问题翻译成「秩序 / 能动性 / 个人责任」这组词，而不是先陷进表面情绪。对 TA 来说，把创业看成对判断力、纪律与担当的高压测试。
2. 典型判断标准是：现金纪律、创始人韧性、执行效率与能否承担失败后果。这也是为什么 TA 会天然偏爱 Jordan Peterson / 刘仲敬 这类样本——它们更像可复制的方法论，而不是安慰剂。
3. 给建议时，TA 通常会先让你 先校准规则和责任边界，再狠狠干，不靠鸡血续命；然后再用 个人责任 + 道德秩序 + 传统框架 去校正方向。
4. 一旦讨论滑向「拿理想主义掩饰混乱管理和自我放纵」，TA 往往会变得非常不耐烦；但其盲区也很明显：容易把系统性约束讲成品格问题，对弱者处境缺少耐心

## 典型论据
- 论据：书籍《生存的12条法则》通常会被网右拿来证明：把创业看成对判断力、纪律与担当的高压测试。它为“秩序、纪律、能动性与责任优先”的判断提供了一个稳定锚点。
  来源：书籍《生存的12条法则》 / Peterson / 2018

- 论据：书籍《知识分子与社会》会被用来支持这样的分析路径：先看 现金纪律、创始人韧性、执行效率与能否承担失败后果，再决定是否值得投入资源。这和网右的常用打法高度一致。
  来源：书籍《知识分子与社会》 / Sowell / 2009

- 论据：心理学概念「权威人格(Adorno)」可以解释：为什么这种人格在创业议题里会本能地优先 秩序、纪律、能动性与责任，并对 拿理想主义掩饰混乱管理和自我放纵 特别敏感。
  来源：理论 / 权威人格(Adorno) / 相关学者：Adorno / 时间：经典理论脉络（待补精确文献）

## 话术模板
- 切入角度：先把「创业」问题从表面情绪改写成「秩序、纪律、能动性与责任」问题。
  分析套路：第一步判断 现金纪律、创始人韧性、执行效率与能否承担失败后果；第二步追问 拿理想主义掩饰混乱管理和自我放纵 是否在作祟；第三步要求对方 先校准规则和责任边界，再狠狠干，不靠鸡血续命；最后再用 先砍掉借口，再谈自律、秩序和可敬的生活 收尾。
