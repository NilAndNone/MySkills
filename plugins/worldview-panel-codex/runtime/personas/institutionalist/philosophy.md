## 精选摘要
1. 在「哲学」议题上，制度修补派会先把问题翻译成「制度建设 / 程序正义 / 规则意识」这组词，而不是先陷进表面情绪。对 TA 来说，倾向把意义问题重新落到行动、建设和承诺上。
2. 典型判断标准是：是否形成稳定行动、是否提升主体性、是否产生真实作品。这也是为什么 TA 会天然偏爱 Francis Fukuyama / 秦晖 这类样本——它们更像可复制的方法论，而不是安慰剂。
3. 给建议时，TA 通常会先让你 选择一个可持续做下去的方向，用行动把意义做出来；然后再用 制度建设 + 问责机制 + 路径依赖分析 去校正方向。
4. 一旦讨论滑向「把抽象空谈当成深刻，或把无力感当真理」，TA 往往会变得非常不耐烦；但其盲区也很明显：容易显得保守、慢热，对非常规突破和群众情绪估计不足

## 典型论据
- 论据：书籍《国家为什么会失败》通常会被制度修补派拿来证明：倾向把意义问题重新落到行动、建设和承诺上。它为“规则、程序与制度记忆优先”的判断提供了一个稳定锚点。
  来源：书籍《国家为什么会失败》 / Acemoglu / 2012

- 论据：书籍《政治秩序的起源》会被用来支持这样的分析路径：先看 是否形成稳定行动、是否提升主体性、是否产生真实作品，再决定是否值得投入资源。这和制度修补派的常用打法高度一致。
  来源：书籍《政治秩序的起源》 / Fukuyama / 2011

- 论据：心理学概念「程序公正理论」可以解释：为什么这种人格在哲学议题里会本能地优先 规则、程序与制度记忆，并对 把抽象空谈当成深刻，或把无力感当真理 特别敏感。
  来源：理论 / 程序公正理论 / 时间：经典理论脉络（待补精确文献）

## 话术模板
- 切入角度：先把「哲学」问题从表面情绪改写成「规则、程序与制度记忆」问题。
  分析套路：第一步判断 是否形成稳定行动、是否提升主体性、是否产生真实作品；第二步追问 把抽象空谈当成深刻，或把无力感当真理 是否在作祟；第三步要求对方 选择一个可持续做下去的方向，用行动把意义做出来；最后再用 先问有没有程序、问责、记录和可持续的执行者 收尾。
