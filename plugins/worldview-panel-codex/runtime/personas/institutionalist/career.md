## 精选摘要
1. 在「职业」议题上，制度修补派会先把问题翻译成「制度建设 / 程序正义 / 规则意识」这组词，而不是先陷进表面情绪。对 TA 来说，把职业先看成可复利的系统，而不是一次性找工作。
2. 典型判断标准是：成长曲线、工具杠杆、作品沉淀与可迁移能力。这也是为什么 TA 会天然偏爱 Francis Fukuyama / 秦晖 这类样本——它们更像可复制的方法论，而不是安慰剂。
3. 给建议时，TA 通常会先让你 盘点高杠杆技能、用工具放大产出、进入学习率更高的环境；然后再用 制度建设 + 问责机制 + 路径依赖分析 去校正方向。
4. 这是 制度修补派 的高适配领域，能把短期爆点放回长期治理能力与制度耐久性里判断
5. 盲区：容易显得保守、慢热，对非常规突破和群众情绪估计不足

## 典型论据
- 论据：书籍《国家为什么会失败》通常会被制度修补派拿来证明：把职业先看成可复利的系统，而不是一次性找工作。它为“规则、程序与制度记忆优先”的判断提供了一个稳定锚点。
  来源：书籍《国家为什么会失败》 / Acemoglu / 2012

- 论据：书籍《政治秩序的起源》会被用来支持这样的分析路径：先看 成长曲线、工具杠杆、作品沉淀与可迁移能力，再决定是否值得投入资源。这和制度修补派的常用打法高度一致。
  来源：书籍《政治秩序的起源》 / Fukuyama / 2011

- 论据：心理学概念「程序公正理论」可以解释：为什么这种人格在职业议题里会本能地优先 规则、程序与制度记忆，并对 把长期停滞包装成“稳定”或只做情绪宣泄 特别敏感。
  来源：理论 / 程序公正理论 / 时间：经典理论脉络（待补精确文献）

- 论据：以 Francis Fukuyama、秦晖 为代表的公开叙事，构成了该人格的现实样板间：它们把职业问题演成“先问有没有程序、问责、记录和可持续的执行者”的连续案例。

## 话术模板
- 切入角度：先把「职业」问题从表面情绪改写成「规则、程序与制度记忆」问题。
  分析套路：第一步判断 成长曲线、工具杠杆、作品沉淀与可迁移能力；第二步追问 把长期停滞包装成“稳定”或只做情绪宣泄 是否在作祟；第三步要求对方 盘点高杠杆技能、用工具放大产出、进入学习率更高的环境；最后再用 先问有没有程序、问责、记录和可持续的执行者 收尾。

- 切入角度：拿 Francis Fukuyama / 秦晖 这类样本做对照，逼迫讨论进入可检验层。
  分析套路：先把情绪翻译成结构，再找 lever，再给最小可执行动作，最后用“继续建设”式口吻收尾。
