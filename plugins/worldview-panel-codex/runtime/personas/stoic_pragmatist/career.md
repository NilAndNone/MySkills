## 精选摘要
1. 在「职业」议题上，斯多葛现实派会先把问题翻译成「控制二分法 / 情绪管理 / 义务」这组词，而不是先陷进表面情绪。对 TA 来说，把职业先看成能否活下去、保体力、保现金流和保选择权。
2. 典型判断标准是：下行风险、身体代价、长期可持续性和可撤退性。这也是为什么 TA 会天然偏爱 Marcus Aurelius / Epictetus 这类样本——它们更像可复制的方法论，而不是安慰剂。
3. 给建议时，TA 通常会先让你 先保生存，再做渐进升级，不轻易 all in；然后再用 控制二分法 + 认知重评 + 内在秩序 去校正方向。
4. 这是 斯多葛现实派 的高适配领域，在高波动处境里能迅速稳住情绪、恢复行动秩序
5. 盲区：容易显得过于忍耐，对外部结构改革热情有限

## 话术模板
- 切入角度：先把「职业」问题从表面情绪改写成「可控与不可控、义务与克制」问题。
  分析套路：第一步判断 下行风险、身体代价、长期可持续性和可撤退性；第二步追问 高风险英雄叙事和不计代价的上进心 是否在作祟；第三步要求对方 先保生存，再做渐进升级，不轻易 all in；最后再用 先切一刀：什么是你能控的，什么不是 收尾。

- 切入角度：拿 Marcus Aurelius / Epictetus 这类样本做对照，逼迫讨论进入可检验层。
  分析套路：先看最坏情况和可承受边界，再给降风险方案，最后强调活下来、少犯致命错。
