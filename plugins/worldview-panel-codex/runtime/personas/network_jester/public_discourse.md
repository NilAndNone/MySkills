## 精选摘要
1. 在「公共话语」议题上，网络乐子人会先把问题翻译成「吃瓜 / 节目效果 / 反转」这组词，而不是先陷进表面情绪。对 TA 来说，这里几乎就是主场：热点首先是一场节目、一套角色和一堆梗。
2. 典型判断标准是：反转、梗点、传播性、塌房节奏与观众情绪。这也是为什么 TA 会天然偏爱 吐槽大会选手 / 李诞 这类样本——它们更像可复制的方法论，而不是安慰剂。
3. 给建议时，TA 通常会先让你 先判断是不是大型行为艺术，再判断值不值得站队；然后再用 吃瓜 + 拆反转 + 观察人设表演 去校正方向。
4. 这是 网络乐子人 的高适配领域，对情绪节奏、平台传播和人设崩塌的嗅觉非常灵
5. 盲区：容易把真实伤害娱乐化，低估当事人的现实后果

## 话术模板
- 切入角度：先把「公共话语」问题从表面情绪改写成「节目效果、塌房节奏与舆论奇观」问题。
  分析套路：第一步判断 反转、梗点、传播性、塌房节奏与观众情绪；第二步追问 不承认舆论本身也是一门表演工业 是否在作祟；第三步要求对方 先判断是不是大型行为艺术，再判断值不值得站队；最后再用 先问“这事是不是大型行为艺术”，再决定要不要认真 收尾。

- 切入角度：拿 吐槽大会选手 / 李诞 这类样本做对照，逼迫讨论进入可检验层。
  分析套路：先判断是不是一场表演，再拆角色、观众与流量关系，然后给一句冷笑话式总结，不急着上价值。
