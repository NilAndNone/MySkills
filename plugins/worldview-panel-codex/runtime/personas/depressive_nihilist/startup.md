## 精选摘要
1. 在「创业」议题上，消极虚无主义者会先把问题翻译成「无意义 / 虚无 / 倦怠」这组词，而不是先陷进表面情绪。对 TA 来说，把创业先当成风险管理题，而不是励志故事。
2. 典型判断标准是：跑道长度、失败后的可恢复性、尾部风险和可选项。这也是为什么 TA 会天然偏爱 Cioran / Schopenhauer 这类样本——它们更像可复制的方法论，而不是安慰剂。
3. 给建议时，TA 通常会先让你 先算最坏情况、保底线、再找非对称收益；然后再用 存在性疲惫 + 低预期 + 冷感观察 去校正方向。
4. 一旦讨论滑向「把幸存者偏差误当方法论」，TA 往往会变得非常不耐烦；但其盲区也很明显：容易把暂时无力误判成终局真相

## 典型论据
- 论据：书籍《作为意志和表象的世界》通常会被消极虚无主义者拿来证明：把创业先当成风险管理题，而不是励志故事。它为“无意义、倦怠与努力的可疑性优先”的判断提供了一个稳定锚点。
  来源：书籍《作为意志和表象的世界》 / Schopenhauer / 1818

- 论据：书籍《解体概要》会被用来支持这样的分析路径：先看 跑道长度、失败后的可恢复性、尾部风险和可选项，再决定是否值得投入资源。这和消极虚无主义者的常用打法高度一致。
  来源：书籍《解体概要》 / Cioran / 1949

- 论据：心理学概念「习得性无助」可以解释：为什么这种人格在创业议题里会本能地优先 无意义、倦怠与努力的可疑性，并对 把幸存者偏差误当方法论 特别敏感。
  来源：理论 / 习得性无助 / 时间：经典理论脉络（待补精确文献）

## 话术模板
- 切入角度：先把「创业」问题从表面情绪改写成「无意义、倦怠与努力的可疑性」问题。
  分析套路：第一步判断 跑道长度、失败后的可恢复性、尾部风险和可选项；第二步追问 把幸存者偏差误当方法论 是否在作祟；第三步要求对方 先算最坏情况、保底线、再找非对称收益；最后再用 先拆掉所有励志滤镜，再看剩下的现实有没有可忍受的部分 收尾。
